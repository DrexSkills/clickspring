Quick start

  1. Create an account at ClickSpring and add your website.
  2. Copy your script from Tracking Setup and paste it before </head> on every page.
  3. Open your site with ?cs_debug=1. A green “ClickSpring ✓” badge confirms it’s working, and Tracking Setup turns green.

That’s it. Page views, button clicks and sign-ups from email forms are tracked automatically.

Install the tracker

<script src="https://drexskills.github.io/clickspring/tracker.js"
  data-site="YOUR_SITE_ID"
  data-endpoint="https://kuzdzlbyxllovbcudzsy.supabase.co"
  data-key="YOUR_PUBLIC_KEY"
  defer></script>

Your exact script, with your IDs filled in, is in ClickSpring → Tracking Setup. The data-key here is a public key and is safe to put in your HTML.

AttributeWhat it does
data-siteYour website’s ID. Required.
data-endpoint, data-keyWhere events are sent. Required. Copy them from Tracking Setup.
data-signup-pathCounts a sign-up when someone reaches this page, e.g. /thank-you. Use it for embedded forms (Mailchimp, ConvertKit, Typeform).
data-base-pathStrips a sub-folder from page names, e.g. /my-repo on GitHub Pages.

What’s tracked automatically

  • Page views, including page changes on single-page apps (React, Next.js, Framer).
  • Clicks on every button and link, named by their text.
  • Sign-ups from any form with an email field.
  • Source (Instagram, TikTok, Google…), tracking link and device (phone, tablet, computer).

Browser SDK

Once the script loads, window.ClickSpring is available on your site.

// Count a sign-up yourself, e.g. after your form's success callback
ClickSpring.signup("waitlist");

// Send any event: "pageview" | "click" | "signup"
ClickSpring.track("click", "Pricing toggle");

HTML attributes

AttributeUse it onWhat it does
data-cs-signupa formCount submitting this form as a sign-up (even without an email field).
data-cs-signup="manual"a formDon’t count on submit. Call ClickSpring.signup() yourself only when it succeeds.
data-cs-click="Name"any elementTrack clicks on it, with this name.
data-cs-ignoreany elementDon’t track clicks inside it (e.g. your menu).

Test mode

Add ?cs_debug=1 to any page URL. A badge shows each event as it’s sent. Test visits are kept out of your stats.

Tracking links

Create a link for each post in ClickSpring → Campaign Links. Each link adds utm_source and cs_c to your URL, so ClickSpring knows which post sent each visitor. The first link a visitor arrives from is remembered, even if they come back later without it.

API keys

Use an API key to pull your stats into your own tools, or to send sign-ups from your server (for example after a payment or email verification).

  1. Open ClickSpring → API Keys.
  2. Name your key and click Create key.
  3. Copy it right away. It starts with cs_live_ and is shown only once.
Keep API keys secret. Use them only on your server, never in website code. If a key leaks, revoke it in ClickSpring and create a new one. Each key belongs to one website.

REST API

Base URL

https://kuzdzlbyxllovbcudzsy.supabase.co/functions/v1/api

Authentication: send your key in the Authorization header on every request.

Authorization: Bearer cs_live_YOUR_KEY

GET /stats

Totals, funnel, traffic sources, devices, top pages, top buttons and exit pages for your website.

daysoptional1–365. Default 30.
curl "https://kuzdzlbyxllovbcudzsy.supabase.co/functions/v1/api/stats?days=30" \
  -H "Authorization: Bearer $CLICKSPRING_KEY"
import { ClickSpring } from "https://drexskills.github.io/clickspring/sdk.js";
const cs = new ClickSpring(process.env.CLICKSPRING_KEY);
const stats = await cs.stats({ days: 30 });
console.log(stats.totals.conversion_rate);
import os, requests
r = requests.get(
    "https://kuzdzlbyxllovbcudzsy.supabase.co/functions/v1/api/stats",
    params={"days": 30},
    headers={"Authorization": f"Bearer {os.environ['CLICKSPRING_KEY']}"},
)
print(r.json()["totals"])

GET /events

Your latest events, newest first. Test-mode events are left out.

limitoptional1–1000. Default 100.
typeoptionalpageview, click or signup.
sinceoptionalISO date, e.g. 2026-11-01.
curl "https://kuzdzlbyxllovbcudzsy.supabase.co/functions/v1/api/events?type=signup&limit=50" \
  -H "Authorization: Bearer $CLICKSPRING_KEY"

POST /events

Send events from your server. One object, or an array of up to 100. Great for counting sign-ups that happen off-page, like a confirmed payment.

Field
typerequiredpageview, click or signup.
visitor_idoptionalLinks the event to a visitor. In the browser it’s localStorage.cs_vid; send it to your server to join the two.
label, pathoptionalButton name and page path.
source, campaign_id, deviceoptionalDefault source is api. Device: mobile, tablet or desktop.
curl -X POST "https://kuzdzlbyxllovbcudzsy.supabase.co/functions/v1/api/events" \
  -H "Authorization: Bearer $CLICKSPRING_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"signup","visitor_id":"VISITOR_ID","label":"paid plan"}'
await cs.signup({ visitorId: req.body.cs_vid, label: "paid plan" });
requests.post(
    "https://kuzdzlbyxllovbcudzsy.supabase.co/functions/v1/api/events",
    json={"type": "signup", "visitor_id": cs_vid, "label": "paid plan"},
    headers={"Authorization": f"Bearer {os.environ['CLICKSPRING_KEY']}"},
)

Response: 201 {"ok": true, "inserted": 1}

Checks your key and returns the website it belongs to.

Errors

Errors return a status code and a JSON body you can show or log:

{ "error": { "code": "invalid_key", "message": "This API key doesn’t exist or was revoked." } }
401missing_key, invalid_key
400bad_json, bad_type, bad_batch, bad_since, bad_event
404not_found
500server_error

JavaScript SDK (server)

A tiny wrapper around the REST API for Node 18+, Deno, Bun and edge functions. No install needed.

import { ClickSpring } from "https://drexskills.github.io/clickspring/sdk.js";
const cs = new ClickSpring(process.env.CLICKSPRING_KEY);

await cs.me();                          // which website this key belongs to
await cs.stats({ days: 7 });            // totals, funnel, sources, devices…
await cs.events({ type: "signup" });    // latest sign-ups
await cs.track({ type: "click", label: "Upgrade" });
await cs.signup({ visitorId, label: "paid plan" });
await cs.campaigns();                   // tracking links with results

On Node, download sdk.js into your project and import it from there. Errors throw a ClickSpringError with status, code and message.

Limits

  • Up to 10 active API keys per website.
  • Up to 100 events per POST /events request.
  • Up to 1,000 events per GET /events request.
  • /stats covers up to 365 days.

Privacy

The tracker uses no cookies, stores no IP addresses with events, never reads what people type, and does nothing when a visitor’s browser sends Global Privacy Control. If you use ClickSpring, add a short note to your own privacy policy: we wrote ready-made text you can copy. See our Privacy Policy and Terms.
